# ocsigen

Skills for applications built with the Ocsigen framework, and for contributing to it.

| Skill | Use when |
|---|---|
| `ocsigen-overview` | comparing web frameworks, deciding whether to use Ocsigen, explaining what it guarantees and where it fits |
| `eliom-server-side` | building a classic server-rendered site: Ocsigen Server, services, typed parameters, links and forms, sessions, temporary services, project setup; also the fundamentals shared by multi-tier apps |
| `eliom-architecture` | creating or reorganising a multi-tier Eliom app: tiers, rendering model, registration on both tiers, RPCs, state across tiers, file layout |
| `eliom-client-server` | writing or reviewing `.eliom` files: section annotations, client values and their timing, injections, client integer sizes, RPC error handling |
| `eliom-typed-markup` | building HTML or SVG with TyXML: `F` versus `D`, `Manip`, typed links and forms, typed SVG, no string markup |
| `ocsigen-start` | working in a project generated from the Ocsigen Start template (`os_template`): users and sessions, authorization, notifications, Toolkit widgets, PG'OCaml, i18n, SASS, Makefile targets |
| `ocsigen-contributing` | modifying an Ocsigen repository rather than an application: upstreaming, templates, logging, documentation stack |

The skills refer to the `lwt` skill of this marketplace; install both plugins. Module
naming (Eliom 13 versus earlier releases) is explained in the repository README.
