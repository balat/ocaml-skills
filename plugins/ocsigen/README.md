# ocsigen

Skills for applications built with the Ocsigen framework, and for contributing to it.

| Skill | Use when |
|---|---|
| `eliom-architecture` | creating or reorganising an Eliom app: tiers, rendering model, services, RPCs, state and scopes, file layout |
| `eliom-client-server` | writing or reviewing `.eliom` files: section annotations, client values and their timing, injections, 31-bit integers, RPC error handling |
| `eliom-typed-markup` | building HTML or SVG with TyXML: `F` versus `D`, `Manip`, typed links and forms, typed SVG, no string markup |
| `ocsigen-start` | working in a project generated from `os_template`: users and sessions, authorization, notifications, Toolkit widgets, PG'OCaml, i18n, SASS, Makefile targets |
| `ocsigen-contributing` | modifying an Ocsigen repository rather than an application: upstreaming, templates, logging, documentation stack |

Module names are those of the development version (`Eliom.Service`, `Os.Session`,
`Ot.Spinner`); see `skills/eliom-client-server/references/module-names.md` for released
names.
